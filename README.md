# Student Performance Analytics System

## Overview

The Student Performance Analytics System is a Python mini-project that
analyzes students' marks and produces a simple academic performance
report. It uses Pandas and NumPy to process student records and applies
Python functions, loops, and conditions to summarize results.

## Main Features

-   Calculates each student's total and average marks.
-   Assigns a grade and Pass/Fail result using the project's rules.
-   Identifies the highest- and lowest-performing students.
-   Calculates the class average and pass/fail counts.
-   Compares average marks across subjects.
-   Displays the top five students.
-   Exports the analysis to `student_performance_report.csv`.

## Technologies

-   Python
-   Pandas
-   NumPy
-   CSV files for input and output

## Grade and Result Rules

Grades are assigned from the student's average: A+ for 90 and above, A
for 80--89.99, B for 70--79.99, C for 60--69.99, D for 50--59.99, and F
below 50. An average of 40 or above is Pass; below 40 is Fail.
